# Site pessoal — Adriano Lisboa

## Estrutura
- `index.html`: página principal
- `css/style.css`: estilos
- `js/script.js`: interações e conteúdo das 11 redações
- `assets/`: fotografias utilizadas na linha do tempo

## Como visualizar
Abra `index.html` no navegador. Para desenvolver, recomenda-se usar o VS Code com a extensão Live Server.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. Entre em **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub Pages publicar e abra o endereço informado na página de configurações.

As redações são versões iniciais para revisão. Leia, ajuste com suas próprias ideias e confira as orientações do professor antes da entrega.
